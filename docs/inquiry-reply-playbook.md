# ACT Creative — 询盘快速处理模板（内部使用，不发布到网页）

目标：先确认收到、再判断是否接单。网站只能减少信息缺失，不能代替实际回复。以下模板均需人工检查并发送；没有配置自动回复或联系任何客户。

## 每天一轮，先分类再报价

- 可以评估：日期、地点、数量/尺寸、参考图、预算已有大部分信息 → 确认范围并决定下一步。
- 信息不完整：一次性索取缺项，不急着找工厂或做完整报价。
- 无法承接：明确拒绝，避免让客户一直等。不要承诺未确认的档期、价格或交付能力。
- 记录：收到日期 / 服务类型 / 状态（待资料、待评估、报价中、已婉拒、成交）/ 下次动作。联系按钮点击不算实际收到询盘。

## 1. 确认收到 + 补资料

Thanks for reaching out to ACT Creative. To review whether we can support this project, could you send the required date, delivery/setup location, quantity and dimensions, reference images or drawings, and an indicative budget? Please mark anything not yet confirmed as TBC. We’ll review the scope and availability before confirming the next step.

谢谢联系 ACT Creative。方便提供需要交付的日期、交付/安装地点、数量尺寸、参考图或图纸，以及大致预算吗？未确定的部分可写待定。我们会先核对范围及档期，再确认下一步。

## 2. 有意向，但尚未确认接单

Thanks, I have the brief. I’m reviewing the production scope and timing. This is not yet a booking or delivery commitment; I’ll confirm what we can take on before we proceed.

需求已收到，我正在核对制作范围和时间。目前还不代表确认接单或预留档期，我会先确认能承接的部分。

## 3. 暂时无法承接

Thank you for considering ACT Creative. We’re unable to take on this brief within the requested timing, so I don’t want to keep you waiting. I’m sorry we can’t support this one.

谢谢考虑 ACT Creative。这次所需时间内我们暂时无法承接，不想耽误你的安排，很抱歉这次不能配合。

## 4. 找回未回复的旧询盘（逐条人工确认）

Hi, apologies for my delayed reply. Is this project still active? If so, please share the current required date and any changes to the scope, and I’ll check whether we can still help. I understand if you’ve already made other arrangements.

不好意思之前回复晚了。这个项目现在还在推进吗？如果还需要支持，可以发我最新时间和需求变动，我再确认是否能配合；如果已经有其他安排，也完全理解。

## 网站数据使用边界

- `Brief entry opened`：点击需求入口；不是有效询盘。
- `Brief started`：首次编辑/选择需求；不是提交。
- `Brief copied`：复制成功；不知道是否发送。
- `Brief email opened` / `Inquiry intent`：尝试打开邮件草稿；不知道是否发出或送达。不要将两类事件相加计为两条线索。
- 真正询盘数量与成交需由邮件/WhatsApp 记录确认。没有完整跟进数据时，不把变化归因于网站版本。
